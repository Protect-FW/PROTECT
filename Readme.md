# Automated Red List assessment reveals hidden extinction risk in one of the world's most diverse freshwater invertebrate families

This repository contains the reproducible analysis for the manuscript on Hydrobiidae extinction risk. The main analysis is [here](https://protect-fw.github.io/PROTECT/extinction_risk.html) and contains all steps and figures.

The folders of this repository contain all files needed to reproduce the results of the manuscript.

## raw_data folder

### Text files:

* all_points.csv: geographic coordinates for ca. 6000 populations
* climate.csv: hydroclimate extracted with QGIS based on these coordinates
* elevation.csv: elevation extracted from digital elevation model with QGIS based on these coordinates
* habitat.csv: Main habitat for 876 species according to the IUCN scheme for habitat classification
* hydrobasins.csv: characteristics of drainage areas
* Hydrobiidae_tacted.log.reproduce.txt, Hydrobiidae_tacted.newick.reproduce.tre, Hydrobiidae_tacted.nexus.reproduce.tre, , Hydrobiidae_tacted.rates.reproduce.csv: Taxonomically augmented phylogeny including all 876 species
* IUCN_labels.txt: IUCN categories for all species, including Data Deficient (DD) and Not Evaluated species
* size.csv: shell length measurement for 1125 populations
* systematics.csv: Subfamily assignment for the species

### Subfolders

* freshwater_ecoregions: GIS shapefile of global freshwater ecoregions obtained from https://feow.org/download and reduced in shape complexity to facilitat creating maps of threatened diversity
    * ecoregions.dbf
    * ecoregions.prj
    * ecoregions.shp
    * ecoregions.shx
* tree_augmentation: files needed for the taxonomic augmentation of phylogenies
    * all_species.csv: table with genus and subfamily assignment for all species
    * all_species.tre: Tree generated by TACT. Will be regenerated by the *tree_augmentation.sh* script
    * Hydrobiidae.tre: Phylogeny from [Delicado et al. 2024](https://onlinelibrary.wiley.com/doi/abs/10.1111/cla.12558)
* tree_distribution: 1000 taxonomically augmented phylogenies in compressed R data format
    * trees.rds


## Forest_et_al_2026

* perc_thrPD.csv: Percentage of threatened evolutionary histroy of major plant and animal groups from [Forest et al. 2026](https://www.science.org/doi/10.1126/science.adz0773)


## IUCNN_input folder

This folder contains all input files for the IUCNN model training. These files are generated from the raw data by executing *data_preparation.Rmd* from the scripts folder and allow to start with the main analysis of extinction risk (*extinction_risk.Rmd*) without the need to run the data aggregation.

* features.txt: species-level geography, hydrology, habitat type, climate, anthropogenic impact, systematic classification, body size, and evolutionary distinctivness values
* feature_stats: mean and standard deviation of the continuous features required to reverse their z-scaling for plotting feature effects
* iucn_labels.txt: IUCN categories for all species, including Data Deficient (DD) and Not Evaluated species


## scripts folder

* data_preparation.Rmd: R markdown file reproducing all steps of data preparation for IUCNN runs
* extinction_risk.RMD: Reproduces modelling of extinction risk and all figures of the manuscript
* helper_functions.R: Additional R functions for extinction_risk.RMD
* tact_to_multiphylo.R: Helper function for generating 1000 taxonomically augmented phylogenies
* tree_agmentation.sh: Shell script for augmenting phylogeny

The scripts in this folder perform three tasks:

### 1. Tree augmentation

To taxonomically augment the DNA based phylogeny of ca. 400 species to include all 876 species, we use the program TACT in a docker container. Check https://tact.jonathanchang.org/ for installation instructions.

The following steps were executed on a Linux machine:

1. Move to the scripts directory

   `cd /.../scripts`

2. Give permission to execute shell scripts

   `chmod +x tree_agmentation.sh`

3. Start docker with root password

   `sudo systemctl start docker`

4. Generate a single augmented tree and safe them it in the *raw_data* folder

   `./tree_agmentation.sh 1`

5. Generate 1000 augmented trees and safe them as R data format. This step also requires the *tact_to_multiphylo.R* script

   `./tree_agmentation.sh 1000`

### 2. Prepare input data for IUCNN analysis

The *data_preparation.Rmd* aggregates all raw specimen- and species-level data into the input format require by the IUCNN package. This R markdown file is best viewed and executed in RStudio. The generated *data_preparation.html* file located in the output folder can be opened in any web browser to inspect all steps of data preparation. Execution of this script will overwrite all files in the IUCNN_input folder.

### 3. Execute IUCNN analysis

The *extinction_risk.Rmd* script trains the neural network models to infer extinction risk and creates all figures and tables of the manuscript. The resulting *extinction_risk.html* file explains and displays all steps in a web browser.


## docs folder

* data_preparation.html: output of *data_preparation.Rmd* script to be viewed in a web browser
* extinction_risk.html: output of *extinction_risk.RMD* reproducing all results and figures of the manuscript
